# Правила работы с проектом

## Git
- Коммиты и пуши — ТОЛЬКО по запросу пользователя
- Команда делает изменения, пользователь сам решает когда коммитить

## Разработка
- Все изменения — сначала локально, потом по запросу на коммит
- Если что-то сломалось — проверить `npm run build` перед пушем
